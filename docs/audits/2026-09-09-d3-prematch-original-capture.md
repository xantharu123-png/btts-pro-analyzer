## Narrow implemented boundary

`sports_prematch.predict_prematch(..., original_capture=...)` optionally exports
the identity, normalized sample, actual fit, unrounded direct values and final
prediction from that same target invocation. It does not rerun the target fit,
predictor, source or any statistical validation. Existing prequential historical
fold fits are part of the original computation, not removed or counted as a new
target computation. The ordinary return type/fields/numbers are unchanged.

The detached `OriginalPrematch` has immutable normalized core parts and a copied
raw source inventory. Raw dictionaries are internal, not native-join/receipt/
approval certificates and not a price-free persisted artifact. Later owning
builders must still qualify and project this data before publication. A missing
or degenerate original stays missing; no coin flip is manufactured.

The actual RisikoBet research adapter has the same explicit optional collector
pass-through. This is a producer seam, not a claim that the outer daily worker
already publishes Basketball/Hockey B3 references. That coordinator, the owning
single-call Base builders and shared normal consumer remain required.

Cricket rejects an explicitly requested new collector. The default Cricket
invocation, code branches, model math, source behavior and serialization remain
unchanged. No source-fetch, context effect, price filter, database or ledger
mutation was added.
