# BetBoy display typeface

Unmodified Barlow Condensed ExtraBold by the Barlow Project Authors.
Bundled under the SIL Open Font License 1.1; see [OFL.txt](OFL.txt).
Source: https://github.com/google/fonts/tree/main/ofl/barlowcondensed

The font is served locally as an embedded CSS font, without a third-party
font request. Only headings use it; body copy retains the system text font.
